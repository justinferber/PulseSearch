## Agreement with the 26 October run

| Comparison | Agreement |
| --- | --- |
| Baseline verdict vs `baseline_oct26_verdict` | **54/54** |

Verdict-level reproduction is exact, which is the meaningful check: the harness re-derives the same
19 → 27 outcome from the same artifacts. Top-1 URL agreement is 44/54 while verdicts match 54/54
because `check_output` compares URL *path suffixes* (`endswith`), so pages that share an expected
suffix, and still-zero-result cases, can differ at the exact-URL level without changing a verdict.
This is reported, not smoothed: the replay is deterministic in verdict, not byte-identical in tie
ordering.

## What this does and does not prove

Proves: the October artifacts are intact and usable; the original pipeline runs end-to-end offline;
BGE reproduces the recorded 19 → 27 recovery with 0 regressions; the run is reproducible from pinned
hashes.

Does not prove: that 27/54 is *good*. The expectations are engineer-authored URL checks
(`ENGINEER_AUTHORED_NOT_INDEPENDENT_HUMAN_LABELS`), 11 cases are fact-status cases with no verified
answer, dense cosine values are not calibrated confidences, and 120 pages from 7 sources say nothing
about global retrieval quality. Independent signed human grading remains 0, so the quality claim stays
HOLD even though the replay itself passed.
