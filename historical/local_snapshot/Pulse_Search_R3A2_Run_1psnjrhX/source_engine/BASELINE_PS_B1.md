# Pulse Search — PS-B1 baseline retained

Mission: stand-alone general-purpose internet search engine, independent discovery, crawler, locally owned index, ranking and versioned query API. Use free/open-source software, no paid search dependencies. Other applications may connect later through public APIs, but are not part of this workstream.

Accepted owner-reported milestones: R1 through R2-P6 local/live crawling and growth, R2-P7 human scoring, R2-P10 nine-question ranking regression, R2-P11 authenticated read-only shadow API. R2-P12 review graded 15 everyday queries; this does not mean internet-wide answer coverage. R2-P13 one-time Brave API diagnostic was completed once and is closed.

R2-P14: opt-in independent sitemap discovery and first-party URL staging. The current implementation does not use paid APIs, does not alter older engines or databases, and must not claim live acceptance before the owner's WSL public-source run.
